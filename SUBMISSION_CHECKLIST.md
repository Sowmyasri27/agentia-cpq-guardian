# Final Submission Checklist

## Project and evidence
- [ ] Confirm current official hackathon rules, required artifacts, character limits, and submission portal.
- [ ] Confirm that the solution meets the event's permitted tools/platform requirements.
- [ ] Build and run the prototype in a clean environment.
- [ ] Run tests and record actual results.
- [ ] Replace mockups with genuine screenshots from your implementation.
- [ ] If Agentia is required, implement and demonstrate the actual supported Agentia workflow; otherwise clearly label integration as planned.
- [ ] Add an architecture diagram that distinguishes implemented and planned components.
- [ ] Review every claim in the deck and README for evidence.

## Repository hygiene
- [ ] Add a license only if you are authorized to choose one.
- [ ] Add `.gitignore` and remove local environments, generated reports, and secrets.
- [ ] Do not upload customer records, internal company code, credentials, or proprietary catalog exports.
- [ ] Add Python version and setup/run commands.
- [ ] Verify repository visibility/access requirements in official rules.

## Demo and submission
- [ ] Record a clear 3–4 minute demo.
- [ ] Show a failing and passing case.
- [ ] Include test output and explain limitations.
- [ ] Verify the required organization/corporate email rule directly in official event instructions.
- [ ] Submit before the verified deadline and save confirmation.
